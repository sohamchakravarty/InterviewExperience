### Construct password from tuples

You are given a set of 3 character tuples in the format of `(a, b, c)` which needs to be used to build a password. The password length will be at max of 7 characters.
The characters in tuples are sorted in the same order as it appears in the password.

Reconstruct the password from the given set of tuples.

**Example:** 

```
b a c
b a d
c d e

result: bacde
```
